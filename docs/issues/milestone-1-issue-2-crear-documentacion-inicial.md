## Criterios de aceptación

- El repositorio incluye una descripción clara del objetivo de la aplicación.
- Un usuario puede seguir los pasos para crear un entorno virtual e instalar dependencias.
- La aplicación se ejecuta con Streamlit siguiendo la documentación.
- Se menciona que el proyecto es educativo y no sustituye a un consejo financiero profesional.
- Se documenta que la MVP no proporciona recomendaciones de inversión ni conexión con bancos.

## Validación

- La sección de inicio de `README.md` describe el proyecto, la ejecución y las limitaciones.
- La configuración de entorno y la ejecución local se documentan con comandos de PowerShell.
- La documentación refleja que los datos se almacenan localmente en SQLite y no se conectan a cuentas bancarias.

## Notas

Este proyecto es una herramienta educativa para aprender Python, GitHub Copilot, GitHub y Streamlit. Sus cálculos y sugerencias están pensados para apoyar la comprensión de finanzas personales, no para reemplazar el criterio profesional ni la asesoría financiera personalizada.
